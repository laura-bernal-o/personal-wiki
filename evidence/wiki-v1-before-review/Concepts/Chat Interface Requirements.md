# Chat Interface Requirements

The chat interface must be functional, using the trained model to generate responses without retraining or modifying the corpus.

## Details

<!-- src:class-4-assignment-brief -->
### In [[Building Custom LLM Assignment]]
- The interface must be able to accept user text and generate a response from the trained nanoGPT. ([[raw/Class 4 - Assignment Brief#Chat with Your Trained Model|§ Chat with Your Trained Model]])
- The interface must show or explain unknown words, the 48-token context limit, and whether each prompt starts fresh. ([[raw/Class 4 - Assignment Brief#Chat with Your Trained Model|§ Chat with Your Trained Model]])
- The chat interface must not retrain the model or add chat messages to the corpus. ([[raw/Class 4 - Assignment Brief#Chat with Your Trained Model|§ Chat with Your Trained Model]])
