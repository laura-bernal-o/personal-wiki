# Building Custom LLM Assignment

This assignment requires building and testing a custom, small language model using a provided notebook, involving corpus expansion, running fixed evaluations, and creating a chat interface.

## Details

<!-- src:class-4-assignment-brief -->
- The submission must include executed versions of the custom_llm.ipynb for both the starter-corpus and corpus-extension experiments. ([[raw/Class 4 - Assignment Brief#What You Are Submitting|§ What You Are Submitting]])
- The evaluation must use the provided 48-case synthetic language eval suite, which must be kept outside the training corpus. ([[raw/Class 4 - Assignment Brief#Run the Provided Language Evals|§ Run the Provided Language Evals]])
- The README must explain the model's learning process using evidence of a token, embedding, gradient, and loss. ([[raw/Class 4 - Assignment Brief#README Requirements|§ README Requirements]])
- The final deliverable is one public GitHub repository URL containing the executed notebook, evidence, and working chat interface. ([[raw/Class 4 - Assignment Brief#Single Deliverable|§ Single Deliverable]])
