# Retrieval Augmented Generation

RAG involves retrieving relevant passages from a local index and including them in a prompt to guide the model's answer generation.

## Details

<!-- src:class-5-personal-wiki-brief -->
### In [[Personal Wiki Assignment]]
- The retrieval tool searches the local index and returns relevant original passages with source paths, serving to find evidence. ([[raw/Class 5 - Personal Wiki Brief|source]])
- RAG supplies context at answer time; it does not train the model. ([[raw/Class 5 - Personal Wiki Brief|source]])
